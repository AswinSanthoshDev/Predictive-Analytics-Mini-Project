# Predictive Analytics Mini Project

## Project Overview

This project demonstrates a complete predictive analytics workflow using Python to predict Customer Lifetime Value (CLV) for an e-commerce business.

## Project Structure

```
predictive-analytics-mini-project/
│
├── data/
├── notebooks/
├── README.md
```

## Workflow

- Exploratory Data Analysis
- Data Cleaning & Preprocessing
- Feature Engineering
- Regression Modeling
- Model Evaluation
- Business Insights

## Dataset

The dataset contains customer demographics, purchasing behavior, engagement metrics, and customer lifetime value.

Target Variable:

- Future_CLV

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
